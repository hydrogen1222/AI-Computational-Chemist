# ORCA resources

> Load this when: the local references do not cover a keyword, a module, or an error message.

- **ORCA 6.1 manual** — https://www.faccts.de/docs/orca/6.1/manual/ — use the manual of the installed
  version; keywords and defaults change between major versions.
  - input structure: `contents/essentialelements/input.html`
  - SCF and convergence: `contents/essentialelements/scf.html`
  - parallel runs: `contents/essentialelements/parallel.html`
  - RI / RIJCOSX: `contents/essentialelements/RI.html`
  - dispersion: `contents/modelchemistries/dispersioncorrections.html`
  - optimizations: `contents/structurereactivity/optimizations.html`
  - frequencies: `contents/structurereactivity/frequencies.html`
  - utilities (`orca_2mkl`, `orca_2aim`, `orca_plot`): `contents/utilitiesvisualization/utilities.html`
  - troubleshooting: `contents/quickstartguide/troubleshooting.html`
- **ORCA forum** — https://orcaforum.kofo.mpg.de — search the exact error string; registration needed to post.
- **ORCA input library** — https://sites.google.com/site/orcainputlibrary/ — community examples; check the
  ORCA version each page was written for.
- **Sobereva (Multiwfn author) notes on ORCA** — http://sobereva.com/list.html — search "ORCA".

Do not commit manuals or binary `.gbw` files to this repository.
